# Examples — per-chapter exercise code

One directory per code chapter of the workshop. On `main` every example is the
complete reference implementation; on the `start/chNN` participant branches the
current chapter onward is replaced with typed stubs (+ TODOs) to implement live.

| Directory | Chapter | Runs with | Try it |
|-----------|---------|-----------|--------|
| [ch04-agent-mind](ch04-agent-mind/) | [4 — The Agent's Mind](../workshop/04-agent-mind/README.md) | nothing (offline) | `pnpm exec ts-node examples/ch04-agent-mind/run.ts` |
| [ch05-execution-loop](ch05-execution-loop/) | [5 — The Execution Loop](../workshop/05-execution-loop/README.md) | emulator + LLM | `pnpm exec ts-node examples/ch05-execution-loop/run.ts` |
| [ch06-self-healing](ch06-self-healing/) | [6 — Self-Healing](../workshop/06-self-healing/README.md) | nothing (offline) | `node examples/ch06-self-healing/self-healer.js` |
| [ch07-observability](ch07-observability/) | [7 — Observability](../workshop/07-observability/README.md) | nothing (offline) | `pnpm exec ts-node examples/ch07-observability/run.ts` |
| [ch08-e2e-demo](ch08-e2e-demo/) | [8 — End-to-End Demo](../workshop/08-e2e-demo/README.md) | emulator | `pnpm test -- --spec examples/ch08-e2e-demo/login.spec.ts` |
| [ch09-agent-ci](ch09-agent-ci/) | [9 — CI with GitHub Actions](../workshop/09-ci-github/README.md) | Ollama | `node examples/ch09-agent-ci/review-locators.js` |

Chapters 1–3 (story, architecture, setup), 10 and 11 are talk/quiz chapters
with no exercise code.

## Workshop branches

```
main          — every example complete (the reference / answer key)
start/ch04    — everything stubbed: implement chapters 4 → 9 yourself
start/ch05    — ch4 complete; implement 5 → 9
start/ch06    — ch4–5 complete; implement 6 → 9
start/ch07    — ch4–6 complete; implement 7 → 9
start/ch08    — ch4–7 complete; implement 8 → 9
start/ch09    — ch4–8 complete; implement 9
```

Joining at chapter N? `git checkout start/chNN` and open the chapter's
`examples/` directory — the `TODO(chN)` comments are the exercise. Stuck, or
want to compare answers afterwards?

```bash
git checkout main -- examples/ch06-self-healing   # restore one chapter's answers
git diff main -- examples/                        # compare your work to the reference
```

Branches are generated by [workshop/build-branches.sh](../workshop/build-branches.sh)
(idempotent; `PUSH=1` to publish).
